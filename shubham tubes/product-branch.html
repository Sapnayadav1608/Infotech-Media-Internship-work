Product Overview

Branch Connection Fittings (Olets)

Branch Connection Fittings (also known as O'lets) are fittings which provide an outlet from a larger pipe to a smaller one (or one of the same size). The main pipe onto which the branch connection is welded is usually called the Run or Header Size.

Types

Olet Range

Weldolet
Weldolet

Butt weld branch outlet fitting for high-pressure, high-temperature piping systems. Provides full reinforcement to the run pipe.

Sockolet
Sockolet

Socket weld branch outlet for small bore high-pressure piping. Branch pipe is inserted into the socket and fillet welded.

Threadolet
Threadolet

Threaded branch outlet fitting for small bore piping where a threaded connection is required on the branch.

Latrolet
Latrolet

Lateral branch outlet fitting providing a 45° branch connection on the run pipe for angled flow diversion.

Elbolet
Elbolet

Branch outlet fitting used on elbows to provide an instrumentation or drain connection on a 90° elbow.

Nippolet
Nippolet

Combined branch outlet and nipple fitting providing a direct threaded or plain end branch connection on the run pipe.

Sweepolet
Sweepolet

Contoured butt weld branch outlet with a smooth sweep radius, reducing stress concentration and turbulence at the branch.

FAQ

Frequently Asked Questions

Branch Connection Fittings (O'lets) are fittings that provide an outlet from a larger run pipe to a smaller branch pipe (or same size). They are welded directly onto the run/header pipe and eliminate the need for a tee fitting, saving weight and cost.

A Weldolet uses a butt weld connection on the branch pipe and is used for larger bore, high-pressure applications. A Sockolet uses a socket weld connection and is used for small bore piping (NPS 2 or smaller) in high-pressure systems.

Our branch connection fittings are manufactured as per ASME B16.11, MSS SP-95 and MSS SP-97 covering forged branch outlet fittings for socket weld, threaded and butt weld connections.
